# CodeOrbit Tech – Java Internship Tasks

## About the Project
This repository contains three Java console applications developed as part of the CodeOrbit Tech internship task.

## Tasks Completed

### 1. Simple Calculator
- Performs addition, subtraction, multiplication, and division.
- Accepts user input using Scanner.
- Handles invalid number inputs and division by zero using exception handling.

### 2. Student Grade Management System
- Stores student names and marks using ArrayLists.
- Calculates average, highest, and lowest marks.
- Displays a formatted student summary report.
- Validates student marks.

### 3. Bank Account Simulation
- Simulates basic banking operations.
- Supports deposits, withdrawals, and balance checking.
- Prevents withdrawals that exceed the available balance.
- Maintains transaction history.

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Scanner
- ArrayList
- Exception Handling
- Switch Statements and Loops

## How to Run
1. Install the Java Development Kit (JDK).
2. Open Eclipse IDE.
3. Create or import a Java project.
4. Place the Java source files in the `src` folder.
5. Open the required Java class.
6. Right-click and select **Run As → Java Application**.
